# Basis

A web browser incremental game project to learn more about Typescript, Vue, SPAs (single page applications), and OOP in regards to game design.

## Version - Pre-Alpha
At this version expect many bugs, imbalanced gameplay, and random oddities left in as I work my way through
my first incremental game (such as an easy way to max resources).

Currently this project links to my main branch but will eventually link to branch version offshoots (such as a1.0.0) once I'm more satisfied with
presenting this game as a project. Perhaps around an hour of gameplay?

I go back and forth between working on gameplay (buildings, jobs, research, ect) and cleaning up the UI to be less of an eyesore.

I am near enough of a point where I could work more on gameplay and some balancing (don't want to go crazy of micro managing balance changes early),
to add content. The UI is far from perfect but I'm reasonably happy that at least you can understand what is going on.
